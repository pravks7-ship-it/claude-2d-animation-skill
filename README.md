# claude-2d-animation-skill

Claude Code skills for 2D/3D animation, motion graphics, video editing, game making and sound design,
vendored from [codepawl/creator-generalist](https://github.com/codepawl/creator-generalist) at commit `b85196c` (MIT, see `.claude/skills/LICENSE-creator-generalist`).

The skills live in `.claude/skills/` and load automatically when Claude Code runs in this repository.

| Skill | Use |
|---|---|
| `2dg`, `2d-generalist` | 2D/2.5D explainer motion graphics (maps, charts, timelines, paper cards) |
| `draw-and-paint-art`, `paint-stylized-backgrounds` | Illustration and stylized backgrounds |
| `edit-video` | Editing in Resolve, FFmpeg, CapCut, Premiere/AE |
| `3dg`, `3d-generalist`, `model-characters`, `rig-characters`, `animate-characters`, `sculpt-models`, `use-3d-software` | 3D pipeline in Blender / three.js |
| `gameg`, `game-generalist` | Playable browser/engine games |
| `watch-video` | Analyse reference videos |
| `design-sound` | Sound design and mixing |

Try: `/2dg map the Silk Road from Chang'an to Constantinople` or `/2dg audit` to check installed tools.
